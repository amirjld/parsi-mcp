# parsi-mcp

[English](README.md) | **فارسی**

سرور MCP برای ابزارهای فارسی و مخصوص ایران، که به دستیارهای هوش مصنوعی (Claude، Cursor، VS Code و ...) توانایی‌های دقیق و آفلاین می‌دهد: تقویم جلالی، اعتبارسنجی کد ملی و کارت و شبا، پردازش متن فارسی، ورودی قیمت با جداکننده‌ی سه‌رقمی و نوشتن مبلغ به حروف، و جعبه‌ابزار راست‌به‌چپ (RTL) برای فرانت‌اند.

بدون نیاز به کلید API و بدون اینترنت اجرا می‌شود. ۵۶ ابزار دارد؛ فهرست کامل در [TOOLS.md](TOOLS.md).

## چرا؟

دستیارهای هوش مصنوعی معمولاً رابط فارسی را چپ‌به‌راست می‌سازند (`margin-left`، `text-left`، فلش‌های برعکس‌نشده، ارقام لاتین) و در جزئیاتی مثل اعتبارسنجی کد ملی، نیم‌فاصله یا تاریخ شمسی اشتباه می‌کنند. parsi-mcp این جزئیات را به‌صورت ابزارهای قابل‌فراخوانی در اختیار آن‌ها می‌گذارد.

## نصب

> به Node.js نسخه‌ی ۱۸ یا بالاتر نیاز دارید. دستورهای `npx` پس از انتشار بسته در npm کار می‌کنند؛ تا آن زمان از [نصب از سورس](#نصب-از-سورس) استفاده کنید.

**Claude Code**

```bash
claude mcp add parsi -- npx -y parsi-mcp
```

یا نصب به‌صورت پلاگین (سرور MCP و مهارت `persian-rtl-frontend` را با هم اضافه می‌کند):

```bash
claude plugin marketplace add amirjld/parsi-mcp
claude plugin install parsi@parsi-mcp
```

**Cursor** (فایل `~/.cursor/mcp.json` یا `.cursor/mcp.json` داخل پروژه)

```json
{ "mcpServers": { "parsi": { "command": "npx", "args": ["-y", "parsi-mcp"] } } }
```

**Claude Desktop** (فایل `claude_desktop_config.json`؛ در ویندوز مسیر `%APPDATA%\Claude\` و در macOS مسیر `~/Library/Application Support/Claude/`)

```json
{ "mcpServers": { "parsi": { "command": "npx", "args": ["-y", "parsi-mcp"] } } }
```

**VS Code** (فایل `.vscode/mcp.json`)

```json
{ "servers": { "parsi": { "type": "stdio", "command": "npx", "args": ["-y", "parsi-mcp"] } } }
```

**مهارت (Skill) برای عامل‌ها** — به عامل می‌گوید رابط فارسی را از ابتدا RTL بسازد و از این ابزارها استفاده کند:

```bash
npx skills add amirjld/parsi-mcp
```

### نصب از سورس

```bash
git clone https://github.com/amirjld/parsi-mcp.git
cd parsi-mcp && npm install && npm run build
# سپس در تنظیمات: { "command": "node", "args": ["/مسیر/کامل/parsi-mcp/dist/index.js"] }
```

## مثال: قبل و بعد

شما می‌گویید: «یک صفحه‌ی پرداخت فارسی با فیلد قیمت بساز.»

**بدون parsi-mcp** معمولاً صفحه‌ای چپ‌به‌راست با `margin-left`، یک فیلد عدد ساده و ارقام لاتین می‌سازد.

**با parsi-mcp** عامل ابتدا راهنمای RTL را می‌خواند، برای چیدمان از `rtl_starter_snippet` و برای فیلد قیمت از `price_input_snippet` استفاده می‌کند و فیلدهای پرداخت را با `validate_card_number` و `validate_sheba` بررسی می‌کند:

```html
<html lang="fa" dir="rtl">
  <!-- با تایپ ۲۰۰۰۰۰ در فیلد، ۲۰۰٬۰۰۰ نمایش داده می‌شود -->
  <input inputmode="numeric" value="۲۰۰٬۰۰۰" />
  <p aria-live="polite">دویست هزار تومان</p>
</html>
```

## امکانات

| بخش | نمونه‌ها |
|---|---|
| تقویم جلالی | تبدیل، قالب‌بندی، پارس، جمع و تفاضل، شبکه‌ی ماه برای انتخاب‌گر تاریخ، بازه‌ی هفته/ماه/فصل/سال (هفته از شنبه)، زمان نسبی («۳ روز پیش»)، محاسبه‌ی سن، اعتبارسنجی تاریخ برای فرم‌ها، روزهای کاری (جمعه تعطیل)، تعطیلات رسمی ثابت شمسی |
| اعتبارسنجی | کد ملی، شناسه‌ی ملی اشخاص حقوقی، کارت بانکی، شبا، موبایل، کد پستی، تشخیص بانک و اپراتور، قالب نمایش شماره تلفن، استخراج آدرس (استان، کد پستی، پلاک/واحد/طبقه) |
| متن فارسی | نرمال‌سازی، نیم‌فاصله، ارقام، عدد و ترتیبی به حروف («بیست و یکم»)، حروف به عدد، اسلاگ، جستجوی فازی، مرتب‌سازی الفبایی فارسی، اصلاح اشتباه کیبورد، آمار متن و زمان مطالعه، تشخیص جهت متن و محافظت bidi، کوتاه‌سازی امن متن، متن نمونه |
| پول | ریال/تومان، جداکننده‌ی سه‌رقمی، مبلغ به حروف، محاسبه‌ی مالیات (نرخ را شما می‌دهید)، خروجی CSV سازگار با اکسل، شکل کوتاه اعداد («۲٫۵ میلیون»)، اعشار و درصد و کسر به حروف |
| فرانت‌اند RTL | راهنما، ممیزی CSS و Tailwind، تبدیل به ویژگی‌های منطقی، قالب‌های شروع، ورودی قیمت، پیش‌تنظیم فونت‌های فارسی |
| داده | ۳۱ استان با کد ISO 3166-2 و مرکز استان |

## یادداشت درباره‌ی داده‌ها

کد BIN بانک‌ها، کد شبا، پیش‌شماره‌ی موبایل و داده‌ی استان‌ها فقط شامل مواردی است که با منابع عمومی تأیید شده‌اند. تعطیلات قمری (مناسبت‌های هجری) بدون تاریخ، چون به تقویم رسمی هر سال بستگی دارند؛ تشخیص پلاک خودرو، حروف به عدد برای شهرها و شهر از روی کد ملی عمداً نیامده‌اند، چون داده‌ی آفلاین قابل‌اعتمادی برایشان تأیید نشد.
